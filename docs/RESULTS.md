# Results

Generated by `paper/build.py` from `results/eval-v1/`, the same files the paper is built from. Do not edit by hand.
Every game behind these numbers passed `scripts/audit_eval.py`, which replays it with its own feedback code (TextArena games are scored by TextArena's engine). Win rate with its 95% bootstrap interval; after the dot, mean guesses in won games.

## Rule sets

| Rule | A guess that is not in the 12,972-word dictionary |
|---|---|
| **strict** (headline) | gets no feedback and uses the turn |
| **retry-3** | does not use a turn, at most three times in a row |
| **open-vocab** | gets feedback like any word; this is the rule of the WordleBench and Jeffers leaderboards, whose code has no dictionary |

**Word-level decoding** is not a rule: the model's output is limited to dictionary words, ranked by the model's own log-probabilities. The code never looks at the clues. It is scored under the strict rule.
